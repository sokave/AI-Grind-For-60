# Indoor Voice

Create `indoor.py` in Python. It should read one line of user input and print the same line with its letters converted to lowercase. Retain the input’s punctuation and whitespace. A visible message asking the user to enter text is optional.

Try the program with uppercase words, a whole sentence, and a number. You may also run `check50 cs50/problems/2022/python/indoor` to check the solution.

Submit by running `submit50 cs50/problems/2022/python/indoor`.
