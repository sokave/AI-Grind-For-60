# Докази використання

| Приклад | Вхідні дані |
| --- | --- |
| 01-mkr | Умова цієї МКР, надана для роботи. Збережено текст зі змінами пробілів у Markdown. |
| 02-indoor-voice| Стислий переказ опису, тестування та здачі вправи. Дедлайн оцінювали за текстом самої вправи.
| 03-mit-ps1 | Стислий переказ вступної частини з правилами здачі й датою.

Кожна папка прикладу містить `assignment.md` з вхідним текстом, `response.json` з відповіддю ChatGPT за форматом проєкту й `checklist.md` з фактичним експортом прототипу. У `01-mkr/` також збережено `reviewed-response.json` і `reviewed.md` з двома пунктами, доданими після звірки зі змістом умови.
