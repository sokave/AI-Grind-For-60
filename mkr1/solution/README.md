# Чекліст із завдання

Прототип формує запит для ChatGPT, перевіряє цитати з відповіді й експортує чекліст у Markdown. Потрібні Python 3 і сучасний браузер. Додаткових бібліотек та API-ключа немає.

## Запуск

З папки `mkr1` запустіть локальний сервер.

```bash
python3 -m http.server 8000 --bind 127.0.0.1 --directory solution
```

Відкрийте [http://127.0.0.1:8000/](http://127.0.0.1:8000/). У Windows за потреби використайте `py -3` замість `python3`.

1. Вставте умову або відкрийте файл `.txt` чи `.md` у кодуванні UTF-8. Натисніть **Підготувати запит**.
2. Скопіюйте запит у ChatGPT. Вставте весь отриманий JSON у поле **Відповідь AI** та натисніть **Зібрати чекліст**.
3. Звірте пункти, дедлайни й повноту за оригіналом. Пункти з відсутніми цитатами виділено. Виправте JSON і зберіть чекліст повторно. Натисніть **Завантажити .md**. Відмітки виконання потрапляють у файл.

Для перевірки без доступу до ChatGPT відкрийте `../evidence/02-indoor-voice/assignment.md` в інтерфейсі й вставте вміст `../evidence/02-indoor-voice/response.json` з редактора. У чеклісті з’являться `indoor.py`, команда `submit50` і повідомлення про відсутність дедлайну в умові.

## Запуск з термінала

Потрібен Node.js 18 або новіший. Виконайте команди з папки `mkr1`.

```bash
node solution/checklist.mjs prompt evidence/02-indoor-voice/assignment.md
node solution/checklist.mjs export evidence/02-indoor-voice/assignment.md evidence/02-indoor-voice/response.json checklist.md
```

Перша команда друкує запит для ChatGPT. Друга обробляє збережену відповідь. Для іншої умови збережіть отриману відповідь у JSON та передайте шляхи до своїх файлів. Без останнього аргументу Markdown виводиться в термінал.
